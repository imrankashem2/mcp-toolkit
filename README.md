# MCP Toolkit

**50 free browser-based utilities for Model Context Protocol developers.**

[Open MCP Toolkit](https://mcptoolkits.freemailcheck.com/) · [Browse all tools](https://mcptoolkits.freemailcheck.com/tools/)

MCP Toolkit is a free developer utility collection for checking, validating, generating, and reviewing MCP-related configuration, protocol structures, security risks, authorization metadata, extensions, migration concerns, schemas, resources, and prompts.

**Current protocol target:** `2026-07-28`

> This repository is the public project/resource page for MCP Toolkit. The production PHP backend is not published here.

## What MCP Toolkit is for

MCP Toolkit is intended for developers who want fast, focused checks while building or reviewing MCP implementations. The tools are designed to help with static validation and developer review; they do not replace implementation-specific testing, security review, or the official MCP specification.

## Privacy

MCP Toolkit's analytics are configured to track tool interaction metadata such as tool runs, success/error outcomes, and copy actions. The analytics layer is designed not to send pasted MCP configurations, prompts, schemas, secrets, OAuth values, request bodies, or result contents to Google Analytics.

Some tools process submitted input through the site's own API endpoints in order to return results. Avoid pasting production secrets into any online utility.
